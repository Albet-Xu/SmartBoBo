## 适用条件（applicable_when）

任何有留出集的机器学习 / 算法实验，尤其需要反复调参时

## 踩到的坑

- 用验证集反复挑配置后还报验证集成绩
- test set 在调参过程中被多次使用

## 尝试过的方案

- ❌ 按验证集成绩反复挑配置 → fail，验证集被当成优化目标，报出的成绩是乐观偏差
- ✅ 调参只看验证集，test set 只在最后跑一次 → success，并如实说明 test set 跑了几次

## 最终做法

调参只用验证集；test set 只在最后跑一次，并在附录如实说明使用次数

## 经验总结（正向）
- 划分方式与使用次数要写进预注册，事后不得改

## 教训总结（负向）
- 一旦某份数据用于调参，它就不再是 test set
