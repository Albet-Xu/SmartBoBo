## 尝试过的方案
- ❌ 方案: camoufox 直接抓文章页 HTML → fail，原因: 拿到的是 MSN 首页推荐流与隐私横幅，正文未加载

- ✅ 方案: requests 直连内容 API → success，原因: 仅默认 UA 即 200，Origin/Referer 非必需

## 最终可行方案

GET https://assets.msn.cn/content/view/v2/Detail/zh-cn/{文章ID} -> JSON（title/abstract/body(HTML)/authors/provider/sourceHref/keywords/readTimeMin）。文章 ID 从 URL 末尾 ar-XXX 段提取（如 ar-AA2buMhB -> AA2buMhB）。全文 Markdown 由脚本 parse_data 组装，无需浏览器。增量采集 manifest 复用模板机制。

## 经验总结（正向）
- MSN 文章首屏不直出正文，先看网络请求找资产域 API，不要对页面 HTML 死磕
- assets.msn.cn 内容 API 公开无签名，带普通 UA 即可请求
- URL 中 ar-XXX 段即文章 ID，可直接拼 API 地址

## 教训总结（负向）
- 直接用 crawler 引擎抓 SPA 文章页，若抓到的是首页推荐流而非正文，说明正文在异步 API 里，应立即切 js-reverse 抓接口
- 网页渲染型 SPA 的 <title> 对 JSON 无效，脚本里取标题要解析 JSON 的 title 字段
