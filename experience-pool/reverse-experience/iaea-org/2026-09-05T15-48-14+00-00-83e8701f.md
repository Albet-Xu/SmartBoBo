## 尝试过的方案
- ❌ 方案: requests 直取列表页/PDF → fail，原因: Cloudflare 拦截；cf_clearance 与浏览器 TLS/JA3 指纹绑定，普通 HTTP 客户端无法复用
- ✅ 方案: camoufox 真实页面导航（page.goto）三步链路 → success，原因: 列表页 ?page=N → 详情页 .publication-actions 提取 PDF → www-pub.iaea.org PDF 200 application/pdf 全链路通过

## 最终可行方案

用 camoufox 单个持久浏览器上下文：1) page.goto(搜索页?page=N) 枚举 h3.card__title>a 链接（分页器 title=\"Go to last page\" 取末页）; 2) 详情页 .publication-actions a[href*=www-pub.iaea.org/MTCD/Publications/PDF] 取 PDF 直链; 3) page.goto(pdf, wait_until=commit).body() 下载字节。勿用 context.request（Node TLS 指纹与 cf_clearance 不匹配会被拒）。

## 经验总结（正向）
- cf_clearance 与 TLS 指纹绑定：Cloudflare 站点必须走真实浏览器导航取数，不能只带 Cookie 用 requests/APIRequestContext
- camoufox page.goto 返回的 Response 可直接 .text()/.body() 取内容，PDF 用 wait_until=commit 最快
- Playwright Response 没有 raise_for_status()，需手动校验 status >= 400
- Drupal 分页器原始 HTML 是相对 href（?page=534），用 title="Go to last page" 定位末页最稳

## 教训总结（负向）
- 不要尝试仅 requests+cf_clearance 复现：指纹不匹配，稳定被拦
- 不改 requests 方案，直接上 camoufox 真实导航，一次到位
