## 1️⃣ 为什么需要它（2 分钟）

**页面大字（三张卡片）：**
- 痛点 1：手动复制 → 慢、错、不可规模化
- 痛点 2：写爬虫 → 要懂代码，且网站反爬强、容易失效
- 价值 1：对话式 → 说一句就采，非程序员也能用
- 价值 2：真实浏览器 → 能执行 JS、处理弹窗/反爬，抓的是"渲染后的完整页面"
- 价值 3：完全本地 → 数据不出本机，安全可控

**讲稿：**
> 先看为什么要做。过去想要网页上的数据，无非两条路：要么人肉复制，效率太低；要么写爬虫，不仅需要编程能力，而且像知乎、淘宝这类网站反爬很严，脚本动不动就失效。
> SmartBoBo 的关键是：把"采集"这件专业事，交给一个本地 AI 智能体。你说一句话，它自己判断要采哪个网址、怎么采、采完怎么存，全程不需要你会代码。而且所有处理都在本机完成，不依赖外部云服务。

## 2️⃣ 它到底能干什么：四种"模式"（2 分钟）

**页面文字（一表，四行）：**
| 模式 | 一句话 |
| --- | --- |
| 采集模式 | 给网址 → 抓取整页存到本地 |
| 逆向模式 | 分析网页背后的数据接口/加密 → 生成可复用爬虫脚本 |
| 工作流模式 | 采集 → 逐字段跟你确认 → 清洗后写入数据库 |
| 标准模式 | 通用 AI 助手，还能给自己装新工具 |

**讲稿：**
> 它主要有四种工作模式，相当于同一个机器人的四种"人设"。
> 最常用的是**采集模式**——给个网址就把页面抓下来；更进一步是**逆向模式**，能反推出网页背后的数据接口、破解参数加密，把"怎么采"做成一个能反复用的爬虫程序；最强的是**工作流模式**，可以直接把采下来的数据整理好、写进你们的数据库里。想要更多能力时，切到**标准模式**，它甚至能自己上网找新工具来装。

## 5️⃣ 它是怎么"长出手脚"的（核心 · 3 分钟）

**页面文字（三块）：**
- ① 自研**采集插件 crawl_fetch**：把"会采集"注册成 AI 能调用的工具
  - 你说话 → AI 判断要采集 → 调工具 → Python 真抓 → 落盘 → 汇报
- ② 通过 **MCP 标准协议**"外接设备"：
  - 逆向分析（查接口/解加密）+ 数据库读表结构
- ③ 通过 **技能库**递"操作手册"：标准化的采集/入库流程照单执行

**讲稿（重点，放慢）：**
> 这一页是这个项目最关键的地方：一个只会聊天的 AI，是怎么变成"会采集数据"的专家的？
> 我们写了一个采集插件，把它注册成 AI 能调用的工具。当你说"采集这个网页"，AI 就"呼叫"这个工具，工具在背后启动 Python 引擎、用真实浏览器把网页抓下来、转成干净文本存到本地，再把结果汇报给你。这一整套自动完成，你不用管。
> 第二，我们用业界标准的 MCP 协议，给 AI"外接设备"——比如逆向分析能力，去查网页背后的数据接口、破解加密；再比如直连你们数据库、读表结构。
> 第三，我们还给 AI 准备了"操作手册"——把采集、入库的标准流程写成技能，AI 照着手册一步步做，既专业又不会乱来。

## 6️⃣ 两个工程亮点（1.5 分钟）

**页面文字（两块）：**
- **多引擎自动降级**：抗检测浏览器 → 轻量引擎 → AI 引擎，一个不行自动换下一个
- **智能代理池**：对付网站 IP 封锁——失效自动换 IP、失败自动重试、全挂主动问你

**讲稿：**
> 为了实现"稳定"，我们做了两个很实用的设计。
> 一是多引擎降级：默认用抗检测浏览器，能对付反爬；万一某台机器环境不行，会自动切换到更轻的引擎，再不行换第三个，保证任务尽量不失败。
> 二是智能代理池：很多网站会封锁频繁访问的 IP，我们就接入了一群代理 IP 自动轮换，挂了自动换，全部失效还会主动问你"要不要走本地网络"，绝不会卡住不动。

## 7️⃣ 数据入库：工作流模式的工程巧思（1 分钟）

**页面文字：**
- "读"(常驻 MCP，快) 与 "写"(脚本进程内批量 UPSERT，省) 分开
- 写库前 **dry-run 预览**，你确认后才真正落库
- 逐字段与你确认含义，**绝不猜测入库**

**讲稿：**
> 如果数据要进数据库，我们的思路是"读写分离"。读表结构用一个一直在线的轻量接口，速度很快；批量写数据则用脚本直接连库，高效且不怕大数据量。安全性上，写库之前会先把"待写入的内容"给你预览确认，每一个字段的意思也会跟你逐个核对——让 AI 去猜你的业务字段，是我们绝不允许的。

## 8️⃣ 安全与合规（1 分钟）

**页面文字：**
- 全程本地运行，数据不出本机，密钥不入版本库
- 只碰你授权的表，参考表只读不写
- 每个有副作用的操作都先说明、后执行，失败不静默

**讲稿：**
> 一个能在你电脑上联网、写文件、写数据库的工具，安全是底线。我们的设计是：数据全部留在本机；数据库只操作你明确授权的表；写库、执行命令这些动作，事前都会告诉你并征得确认。简单讲就是——**透明、可控、有边界**。
