# MCP 工具与技能库功能优化操作指南

## 概述

本次优化对设置面板中的 **MCP 工具管理** 和 **技能库管理** 两个页面进行了全面升级，包括 UI 样式改进、新功能实现和后端 API 扩展。

---

## 一、UI 样式优化

### 1. 下拉菜单箭头居中（Select → Menu 组件）

**改前问题：** 原生 `<select>` 元素的三角箭头由浏览器渲染，位置偏右，美感差。

**改后方案：** 使用项目自带的 `Menu` 组件（`ui-primitives/Menu.tsx`）替换原生 `<select>`，下拉箭头自动居中。

**涉及文件：**
- `ui-settings-mcp/src/client/MCPToolsSection.tsx`
- `ui-settings-skills/src/client/SkillsSection.tsx`

### 2. Toggle 开关样式优化 + 滑动动效

**改前问题：** 内联样式仅有背景色变化，无白色圆球滑块，无滑动动画。

**改后方案：** 启用 CSS 模块中已定义但未使用的 `.toggle` / `.toggleSlider` 样式：
- **胶囊形轨道**（border-radius: 22px）
- **白色圆形滑块**（`::before` 伪元素，16×16px）
- **0.3s ease 滑动动效**（`transform: translateX(18px)`）
- **蓝色主题色保持不变**（`--dsw-alias-primary`）

**涉及文件：**
- `ui-settings-mcp/src/client/MCPToolsSection.module.css`
- `ui-settings-skills/src/client/SkillsSection.module.css`

### 3. 按钮样式统一

所有按钮（安装、批量操作、对话框按钮）从内联样式改为 CSS 模块类：
- `.installButton` — 蓝色主按钮
- `.filterButton` — 筛选按钮（带 chevron）
- `.batchButton` / `.batchButtonDanger` — 批量操作按钮
- `.dialogButtonPrimary` / `.dialogButtonSecondary` — 对话框按钮

## 二、MCP 工具管理 — "安装"按钮功能

### 功能说明

点击"安装"按钮后弹出配置对话框，用户填写 MCP 工具信息后确认安装。

### 操作步骤

1. 打开 **设置 → MCP 工具**
2. 点击右上角 **"安装"** 按钮
3. 在弹出的对话框中填写以下字段：
   - **服务器名称**（必填）：如 `js-reverse`、`context7`
   - **传输方式**：选择 `stdio`（本地进程）或 `streamable-http`（远程 HTTP）
   - **命令**（stdio 模式）：如 `npx -y @some/mcp-server`
   - **参数**（stdio 模式）：空格分隔的命令行参数
   - **环境变量**（stdio 模式）：`KEY=value` 格式，每行一个
   - **URL**（HTTP 模式）：如 `http://localhost:3000/sse`
   - **超时时间**：默认 120000ms
   - **启用重连**：勾选启用自动重连
4. 点击 **"安装"** 确认

### 技术实现

- 后端：通过 `mcpTools.install` RPC 方法将配置写入 `ctx.settings`（`mcpTools` 键）
- 前端：`MCPToolsStore.install()` 调用 `api.mcpTools.install(config)`
- 配置文件位置由 host 的 settings provider 决定

## 三、技能库管理 — "安装"按钮功能

### 功能说明

点击"安装"按钮后调用系统文件夹选择器，用户选择本地技能包文件夹后自动安装。

### 操作步骤

1. 打开 **设置 → 技能库**
2. 点击右上角 **"安装"** 按钮
3. 在弹出的下拉菜单中选择 **"从本地文件安装"**
4. 系统弹出文件夹选择器，导航并选择技能包所在的文件夹（该文件夹需包含 `SKILL.md` 文件）
5. 选择后程序自动读取 `SKILL.md` 提取技能名称和描述，将其添加到技能列表

### 技术实现

- 前端：调用 `api.host.pickDirectory({})` 打开系统文件夹选择器
- 后端：`skill.installLocal` RPC 方法读取所选目录的 `SKILL.md`，提取元数据后写入 `skillLibrary` 配置
- 如果 `SKILL.md` 不存在，技能名称将使用文件夹名称

## 四、技能库管理 — 分组功能

### 功能说明

支持对技能进行分组管理，可创建、重命名、删除分组，并将技能移入/移出分组。

### 分组导航栏

技能列表上方新增分组导航栏：
- **"全部"** — 显示所有技能（默认选中）
- **自定义分组** — 显示该分组下的技能
- **"未分组"** — 显示不属于任何分组的技能
- **"+ 新建分组"** — 创建新分组

### 操作步骤

#### 创建新分组
1. 点击分组导航栏右侧的 **"+ 新建分组"**
2. 在弹出的对话框中输入分组名称
3. 点击 **"保存"** 或按 Enter 确认

#### 重命名分组
1. 右键点击分组标签（或长按）
2. 选择 **"重命名"**
3. 输入新名称后按 Enter 确认

#### 删除分组
1. 右键点击分组标签
2. 选择 **"删除分组"**
3. 确认后分组被删除，分组内的技能变为"未分组"状态

#### 将技能移入分组
1. 勾选一个或多个技能
2. 在批量操作栏中点击 **"移入分组"** 按钮
3. 在下拉菜单中选择目标分组

#### 安装技能时选择分组
1. 点击"安装"→"从本地文件安装"
2. 选择文件夹后，技能默认加入当前选中的分组（或"未分组"）

### 技术实现

- `SkillConfig` 接口新增 `group?: string | null` 字段
- `SkillsState` 新增 `groups: SkillGroup[]` 存储分组列表
- 分组配置通过 `skillLibrary` 键持久化在后端 settings 中
- 后端提供 `createGroup`、`renameGroup`、`deleteGroup`、`moveSkillsToGroup` 四个 RPC 方法

### 修改文件

同"安装"功能 + `ui-settings-skills/src/client/locales.ts`（新增分组相关翻译词条）。
