## 技术说明

### 自定义提供方配置的三要素

对于 **不在 pi-ai catalog 中** 的提供方，必须配置三个要素：

```yaml
your-provider:
  apiKeyEnv: YOUR_API_KEY      # 1. 凭据引用（必需）
  api: openai-completions      # 2. API 协议类型（必需）
  models:                      # 3. 模型列表（必需）
    - id: model-1
      name: Model 1
      contextWindow: 100000
```

### 支持的 API 协议类型

`api` 字段接受以下值：

| 协议类型 | 说明 | 适用提供方 |
|---------|------|-----------|
| `openai-completions` | OpenAI Chat Completions API | Moonshot、OpenCode Go、大多数国产模型 |
| `openai-responses` | OpenAI Responses API | 新版 OpenAI 接口 |
| `anthropic-messages` | Anthropic Messages API | Claude 系列 |
| `google-generative-ai` | Google Generative AI | Gemini 系列 |
| `deepseek-chat` | DeepSeek Chat API | DeepSeek 官方 |

### 为什么需要指定 API 协议？

pi-ai 适配器支持多种 LLM API 协议：

```
不同提供方的 API 协议格式不同
    ↓
- OpenAI: /v1/chat/completions
- Anthropic: /v1/messages
- Google: /v1/models:generateContent
    ↓
pi-ai 需要知道使用哪种协议格式
    ↓
才能正确构建请求
```

**如果不指定 `api`：**
- pi-ai 无法知道如何构建请求
- 启动时验证失败
- 报错：`needs an api`

## 配置检查清单

添加新提供方时，请逐项检查：

### 必填字段

- [ ] `apiKeyEnv` - 凭据引用名称
- [ ] `api` - API 协议类型（非 catalog 提供方必需）
- [ ] `models` - 模型列表（非 catalog 提供方必需）

### 模型列表检查

- [ ] 至少包含一个模型
- [ ] 每个模型有 `id` 字段
- [ ] `id` 非空且唯一
- [ ] （推荐）配置 `name` 显示名称
- [ ] （推荐）配置 `contextWindow` 上下文窗口

### YAML 语法检查

- [ ] 缩进正确（2 空格）
- [ ] 列表项使用 `-`
- [ ] 键值对使用 `:`
- [ ] 字符串无需引号（除非包含特殊字符）

## 常见错误示例

### 错误 1：缺少 api 字段

```yaml
# ❌ 错误
moonshot:
  apiKeyEnv: MOONSHOT_API_KEY
  models:
    - id: moonshot-v1-8k

# ✅ 正确
moonshot:
  apiKeyEnv: MOONSHOT_API_KEY
  api: openai-completions
  models:
    - id: moonshot-v1-8k
```

### 错误 2：api 值不正确

```yaml
# ❌ 错误（拼写错误）
moonshot:
  api: openai-completion  # 少了 's'

# ✅ 正确
moonshot:
  api: openai-completions
```

### 错误 3：模型列表为空

```yaml
# ❌ 错误
moonshot:
  apiKeyEnv: MOONSHOT_API_KEY
  api: openai-completions
  models: []

# ✅ 正确
moonshot:
  apiKeyEnv: MOONSHOT_API_KEY
  api: openai-completions
  models:
    - id: moonshot-v1-8k
```

### 错误 4：缩进不正确

```yaml
# ❌ 错误（缩进混乱）
moonshot:
apiKeyEnv: MOONSHOT_API_KEY
  api: openai-completions
    models:
    - id: moonshot-v1-8k

# ✅ 正确
moonshot:
  apiKeyEnv: MOONSHOT_API_KEY
  api: openai-completions
  models:
    - id: moonshot-v1-8k
```
