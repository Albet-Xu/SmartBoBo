# 29-设置界面前端优化操作指南

> 本指南记录对设置界面「代理池」「MCP 工具」「技能库」三处前端交互的一轮优化：代理源卡片折叠与拖拽排序、筛选下拉箭头贴身、MCP 卡片开关位置与样式调整。均为前端（client 插件包）改动，后端数据模型与取用逻辑未变更。

---

## 一、需求与最终方案

| 需求 | 现象/目标 | 最终方案 |
|---|---|---|
| 1. 代理源卡片折叠 + 拖拽排序 | 代理池多个代理源时，卡片推荐可折叠；取用优先级按列表从上到下，希望能拖拽调整顺序 | 卡片默认折叠，只显示名称；点击或 ▸ 箭头展开；左侧「≡」拖拽把手可上下调整顺序，保存后生效 |
| 2. “全部”下拉箭头贴身 | 原生 `<select>` 箭头被钉在控件右缘，与“全部”等短文字之间留白过大 | 换成自绘下拉：文字与小箭头只隔一个空格（`gap:4px`），沿用现有 `Menu` 组件 |
| 3. MCP 卡片开关 | 希望有单独开关控制每个 MCP | 初版曾把开关移到左侧并放大为 iOS 风格；经确认**恢复右侧原样式**，开关仍在卡片右侧，尺寸与动画不变 |

> 第 3 项最终保持原生形态：选择复选框在左、开关在右，未在卡片左侧新增 iOS 风格开关（避免双开关）。

## 三、实现说明

### 1. 代理池：代理源卡片折叠 + 拖拽排序（`ProxyPoolSection.tsx`）

**折叠（默认折叠）**
- 用一个 Set 记录**已展开**的卡片下标 `expanded: Set<number>`，默认空 → 所有卡片默认折叠。
- 折叠态只显示：【拖拽把手 `≡` / 展开箭头 `▸` / 代理源名称 / 删除】；展开态显示名称输入框、API 地址和收起箭头 `▾`。
- 折叠/展开是**纯界面状态，不持久化**；新增代理源同样默认折叠。

**拖拽排序**
- 用 HTML5 原生拖拽（`draggable` + `onDragStart/onDragOver/onDragEnd`），拖拽把手在整卡左侧。
- 拖放后重排 `localConfig.sources` 数组并置 `edited=true`，仍由右上角「保存」按钮写入 `proxy-pool` 设置命名空间。
- 列表上方提示“拖动卡片可调整顺序，越靠上优先级越高”。

### 2. 下拉箭头贴身（`MCPToolsSection.tsx` / `SkillsSection.tsx`）

- 用本地小组件 `FilterMenu` 替换原生 `<select>`：触发器是一个按钮（当前选项文字 + `IconChevronDownOutline14`），两者间距 `gap:4px`（约一个空格）；点击用 `ui-primitives` 的 `Menu` 弹出选项列表，展开时箭头旋转 180°。
- 覆盖范围：MCP 工具的「状态」筛选、技能库的「状态」和「来源」两个筛选（都从“全部”开头）。
- CSS（各包 `.module.css`）：`.filterTrigger`（按钮/间距/边框）、`.filterChevron`、`.filterOpen`（旋转）。

### 3. MCP 卡片开关（`MCPToolsSection.tsx` + `.module.css`）

- 每个 MCP 卡片的布局保持原始：**选择复选框在左、开关在右**。
- `.toggle` 尺寸还原为 40×22 胶囊、圆球滑块 16px、滑块位移 18px、轨道圆角 22px，均与改动前一致；开关逻辑仍走 `controller.toggle`。

## 四、构建与验证

**类型检查**（已确认通过）：

```sh
cd dsh
pnpm exec tsc --project packages/client/ui-settings-proxy/tsconfig.json --noEmit
pnpm exec tsc --project packages/client/ui-settings-mcp/tsconfig.json --noEmit
pnpm exec tsc --project packages/client/ui-settings-skills/tsconfig.json --noEmit
```

**重建 + 重启**：

```sh
cd dsh
pnpm run build:lib:client   # 重建全部 client 插件包的运行时 bundle
pnpm bobo                    # 重启（服务端口 7070）
```

> 说明：这几个设置插件包是**运行时 bundle**（由 tsdown 打包、经客户端模块系统加载），不在 vite shell 里打包，所以只需重建 `build:lib:client`，无需 `build:web`；`dbx-runtime`（4224 端口，数据库面板）与本次改动无关。

**手动点测**（在浏览器打开 `http://127.0.0.1:7070`）：
1. 设置 → 代理池：代理源卡片默认折叠，点击/▸ 展开；拖动 `≡` 调整顺序后点「保存」，重进页面顺序保留。
2. 设置 → 代理池 → MCP 工具 / 技能库：下拉的小箭头只距文字约一个空格，点击弹出选项、选择生效。
3. 设置 → MCP 工具：卡片选择复选框在左、开关在右，开关仍能单独控制每个 MCP。

## 五、注意事项

1. **折叠状态不持久化**：折叠/展开仅保存在组件内存，刷新页面后恢复默认（全部折叠）。
2. **顺序即优先级**：拖拽只重排本地数组，需点「保存」才写入并影响取用优先级；后端按数组顺序取用，无需改动。
3. **下标索引边界**：折叠状态按卡片下标记录，拖拽重排后折叠状态可能随下标偏移跟随到别的源；当前仅影响界面观感，不影响数据正确性。如后续需要可改为按代理源身份记录。
