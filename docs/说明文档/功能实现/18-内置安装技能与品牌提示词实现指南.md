# 18-内置安装技能与品牌提示词实现指南

> 本指南记录本次「内置技能 + 品牌提示词」两轮功能改动的**具体操作流程、改动文件、如何以后自己改提示词**，方便快速定位与维护。

---

## 1. 改动总览

本次共实现两个功能：

1. **品牌问候应答（需求 2）**：检测到「你好 / hello / 你是谁？」等问候、身份询问关键词时，固定以 BoBo 身份回应，压掉模型自带的 MiMo / 小米系自我介绍。
2. **内置安装 MCP / Skills 技能（需求 1）**：新增一个**模型可调用、前端「技能库」不可见、不可修改**的隐藏技能，负责从 GitHub 安装 MCP 服务器或技能包；并在精简模式（采集/极简）下引导用户切换到「标准模式」安装。

> 说明：当前用户模型为 `mimo-v2.5`（`opencode-go` 提供商）。「你好，我是 MiMo…」这句是模型**凭训练知识自报家门**输出的，项目代码里没有这句话，所以只能靠**提示词规则**压制，而不是改某个字符串。

## 3. 以后怎么自己改「品牌问候话术」

改动关键词、BoBo 身份话术，共 5 个文件、同一个段落，改一处即可但**四处都同步改**（standard / code / cordis / minimal / crawl）。

**定位**：每个文件的 `- id: persona` → `config: text:`，用文本搜索关键词 `你的正式身份是 BoBo` 即可定位到该段。

**当前固定话术（可改）**：
```
你的正式身份是 BoBo，一个由许建波同学开发的 AI 智慧采集小助手，运行在 SmartBoBo Agent 环境中。
当用户使用问候或身份询问关键词（如“你好”“hello”“hi”“你是谁”“你是谁？”“介绍一下你自己”等）时，
你必须将回复的第一句话设为：“你好！我是 BoBo，一个由许建波同学开发的 AI 智慧采集小助手。我目前运行在
SmartBoBo Agent 环境中，主要功能包括网页采集、MCP 工具与技能扩展等。”这些关键词即使夹在其他句子中也必须命中。
禁止自称 MiMo 或任何小米系产品身份。
```

**想改的东西**：
- 改**关键词**列表：在括号里增删（如加「嗨」「早上好」）。
- 改**应答话术**：改 `第一句话设为：“…”` 里的内容。
- 改**名字 / 开发者**：直接把上文里的「BoBo」「许建波」「AI 智慧采集小助手」改成新内容。
- 生效：改完需**重启服务**（见 §6）让预设在下次启动时重新加载。

> 小提示：`name`/`description` 段与下面 §4、§5 的段落都是 `persona` 的 `text` 的不同段落。折叠标量 `>-`（或 `|-`）内用空行分隔段落，保持每行开头的缩进（6 个空格）即可，别破坏缩进层级。

## 4. 以后怎么自己改「引导切标准模式」话术

这条只存在于**采集（crawl）**与**极简（minimal）**两个预设。用文本搜索 `不具备从 GitHub 安装` 定位。

**当前话术（可改）**：
```
你所在模式工具集精简，不具备从 GitHub 安装 MCP 服务器或技能包的能力。当用户请求安装 MCP 或 Skills 时，
请友好引导用户：进入 设置 → Agent 预设 → 选择「标准模式」，切换后重新发起安装请求；标准模式下可调用内置技能完成安装。
请勿在当前模式下尝试直接安装。
```

## 5. 以后怎么自己改「能力认知 / 安装流程」

- **能力认知话术**（standard / code / cordis 三处）：搜索 `你具备从 GitHub 安装` 定位，改的是"模型自认为拥有安装能力"的描述，不是真正安装逻辑。
- **真正安装逻辑（SOP）**：在 `./agents/skills/install-mcp-and-skills/SKILL.md` 里。
  - 改安装流程、写配置文件路径、去重规则、安全红线，都改这一个文件。
  - 该文件 frontmatter 的 `name`/`description` 会作为技能在模型侧技能目录里展示；`user-invocable: false` 保证它不进入用户可调用/可修改入口。
  - 生效：技能发现是**实时**的（`skill-filesystem` 的 Chokidar 监听），改动无需重启。

| 改动类型 | 生效方式 |

| 5 个预设的 persona 提示词 | 需**重启服务**：在 `dsh/` 目录执行 `pnpm bobo`（预设只在启动时加载） |

| 安装 MCP 服务器（AI 执行时） | 写配置后也需重启才挂载 |

## 7. 验证方法

1. **品牌问候**：进入任一模式，发「你好」/「你是谁？」，期望首句回「你好！我是 BoBo，一个由许建波同学开发的 AI 智慧采集小助手…」，且不再提 MiMo。
2. **隐藏技能可见性**：进「标准模式」对话，让模型加载技能目录应能看到 `install-mcp-and-skills`；进「设置 → 技能库」应**看不到**该技能（不可见、不可改）。
3. **安装引导**：在「采集模式 / 极简模式」发「帮我安装 XX MCP」，期望模型引导你去「标准模式」而不会真的去装。
4. **真实安装**：在「标准模式」发「帮我从 GitHub 安装一个 filesystem MCP / 某个技能」，观察其按 SOP 写 `cordis.patch.yml`、`settings.yaml`（MCP）或 `~/.dsh/skills/<name>/`（技能），并按提示重启后可正常使用。

## 8. 关联概念速查

- **MCP 安装两处写入**：挂载靠 `~/.dsh/cordis.patch.yml` 里的 `mcp-client` 实例（启动时加载）；列表展示靠 `~/.dsh/settings.yaml` 的 `mcp-tools` 命名空间（前端「MCP 工具」读取）。两者都要写。
- **技能发现根目录**：`skill-filesystem` 扫描 `项目根/.agents/skills/`（不可改、随项目走）与 `~/.dsh/skills/`（用户可自行装）。前端「技能库」只管 `skill-library` 命名空间，故放 `.agents/skills/` 天然对 UI 隐藏。
- **DSH 主目录**：`$DSH_HOME` 默认 `~/.dsh`（当前机器即 `C:/Users/Albet/.dsh`）。
