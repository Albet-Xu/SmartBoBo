# 采集逻辑优化说明文档

## 1. 优化背景

原有的采集逻辑存在以下问题：
1. 采集结果直接保存为 HTML 文件，不利于阅读和后续处理
2. 保存位置固定为 `BoBo/data/` 目录，不够灵活
3. 没有利用开源的 HTML 转 Markdown 库来优化输出格式

本次优化旨在：
1. 将采集结果从 HTML 格式转换为 Markdown 格式
2. 默认保存位置改为当前工作区的 data 文件夹
3. 集成 html2text 库实现高质量的 HTML 到 Markdown 转换

## 2. 优化内容

2. **修改文件名生成函数**：
```python
def build_filename(url: str, title: str) -> str:
    host = urlsplit(url).netloc.replace('www.', '')
```

3. **添加 HTML 转 Markdown 逻辑**：
```python
# 将 HTML 转换为 Markdown
h = html2text.HTML2Text()
h.ignore_links = False
h.ignore_images = False
h.ignore_emphasis = False
h.body_width = 0  # 不自动换行
h.unicode_snob = True  # 使用 Unicode 字符
h.skip_internal_links = False
h.inline_links = True
h.ignore_images = False
h.images_to_alt = False
h.single_line_break = False

# 如果指定了选择器，只转换选择器匹配的内容
if selector:
    try:
        el = page.locator(selector).first
        if await el.count() > 0:
            selected_html = await el.inner_html()
            markdown = h.handle(selected_html)
        else:
            markdown = h.handle(html)
    except Exception:
        markdown = h.handle(html)
else:
    markdown = h.handle(html)
```

4. **保存 Markdown 文件**：
```python
# 保存 Markdown 文件
Path(out).parent.mkdir(parents=True, exist_ok=True)
with open(out, 'w', encoding='utf-8') as f:
    f.write(markdown)
```

### 2.2 默认保存位置优化

#### 2.2.1 修改 tool-acquisition 插件

**修改文件**：`BoBo/dsh/packages/acquisition/tool-acquisition/src/index.ts`

**修改内容**：

1. **添加动态路径获取函数**：
```typescript
/**
 * 获取当前工作区的 data 目录
 * 如果配置了 dataDir，则使用配置的路径
 * 否则尝试获取当前工作区路径，返回其下的 data 文件夹
 */
function getDataDir(config: Config, workspacePath?: string): string {
  // 如果配置了 dataDir 且不为空，使用配置的路径
  if (config.dataDir && config.dataDir.trim() !== '') {
    return config.dataDir
  }

  // 尝试获取当前工作区路径
  if (workspacePath) {
    const dataDir = join(workspacePath, 'data')
    // 确保目录存在
    if (!existsSync(dataDir)) {
      try {
        mkdirSync(dataDir, { recursive: true })
      } catch {
        // 如果创建失败，回退到默认路径
      }
    }
    return dataDir
  }

  // 最终回退到 BoBo/data 目录
  return 'data'
}
```

2. **修改工具参数**：
```typescript
parameters: {
  // ... 其他参数
  saveDir: {
    type: 'string',
    description: 'Optional directory to save the file; default is the current workspace\'s data folder.',
  },
}
```

3. **修改执行逻辑**：
```typescript
async execute(args, _exec) {
  // ... 其他逻辑

  // 确定保存目录：优先使用用户指定的 saveDir，然后是配置的 dataDir，最后是工作区的 data 文件夹
  let dataDir: string
  if (args.saveDir) {
    dataDir = args.saveDir
  } else {
    dataDir = getDataDir(config)
  }

  // ... 其他逻辑
}
```

## 3. 技术实现细节

### 3.1 HTML 转 Markdown 配置

html2text 库的配置选项：

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `ignore_links` | `False` | 保留链接 |
| `ignore_images` | `False` | 保留图片 |
| `ignore_emphasis` | `False` | 保留强调文本 |
| `body_width` | `0` | 不自动换行 |
| `unicode_snob` | `True` | 使用 Unicode 字符 |
| `skip_internal_links` | `False` | 不跳过内部链接 |
| `inline_links` | `True` | 使用内联链接格式 |
| `images_to_alt` | `False` | 保留图片而非转换为 alt 文本 |
| `single_line_break` | `False` | 不压缩换行 |

### 3.2 保存路径优先级

1. **用户指定路径** (`saveDir` 参数)：最高优先级
2. **配置的 dataDir**：次优先级
3. **当前工作区 data 文件夹**：默认选项
4. **BoBo/data 目录**：最终回退

### 3.3 文件命名规则

- **自动生成**：`站点_标题_时间戳.md`
- **自定义命名**：用户指定的文件名 + `.md` 扩展名

## 4. 使用示例

### 4.1 基本采集

**用户输入**：
```
请采集 https://example.com
```

**Agent 行为**：
1. 调用 `crawl_fetch` 工具
2. 使用 camoufox 引擎采集网页
3. 将 HTML 转换为 Markdown
4. 保存到当前工作区的 `data/` 目录
5. 返回保存路径和内容预览

**预期输出**：
```
采集完成：
- 已保存: E:/SmartBoBo/my-workspace/data/example.com_PageTitle_20240101-120000.md
- HTTP状态: 200
- 预览: 这是页面内容的预览...
```

### 4.2 指定保存位置

**用户输入**：
```
请采集 https://example.com，保存到 E:/我的项目/docs/ 目录
```

**Agent 行为**：
1. 调用 `crawl_fetch` 工具，指定 `saveDir` 参数
2. 将采集结果保存到指定目录

### 4.3 指定文件名

**用户输入**：
```
请采集 https://example.com，保存为 my-article.md
```

**Agent 行为**：
1. 调用 `crawl_fetch` 工具，指定 `outFile` 参数
2. 将采集结果保存为指定文件名

## 6. 注意事项

### 6.1 依赖安装

- 需要重新运行 `uv sync` 安装 html2text 依赖
- 确保 Python 环境正确激活

### 6.2 文件格式

- 所有采集结果现在保存为 `.md` 文件
- 文件编码统一使用 UTF-8
- Markdown 格式兼容主流编辑器

### 6.3 路径处理

- Windows 路径使用正斜杠 `/`
- 确保目录存在且有写入权限
- 路径中避免特殊字符

### 6.4 性能影响

- HTML 转 Markdown 会增加少量处理时间
- 对于大型网页，转换时间可能较长
- 建议设置合理的超时时间
