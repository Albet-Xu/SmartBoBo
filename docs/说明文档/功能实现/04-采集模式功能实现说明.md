# 采集模式功能实现说明文档

## 1. 功能概述

采集模式是 BoBo 智能采集平台的核心功能之一，通过 Agent 预设系统实现智能检测用户输入中的网址链接并自动调用本地采集引擎抓取网页内容。本文档详细说明采集模式的技术实现细节。

## 2. 系统架构

### 2.1 整体架构

```
用户输入 → Agent 预设系统 → Persona 提示词 → 工具调用 → 采集脚本 → 结果保存 → 结果汇报
```

### 2.2 核心组件

1. **Agent 预设系统**：管理预设配置和插件组合
2. **Persona 插件**：提供采集专用提示词和行为规则
3. **采集工具插件** (`tool-acquisition`)：Node.js 编排层
4. **Python 采集脚本**：实际执行网页抓取
5. **本地文件系统**：保存采集结果

## 3. 技术实现细节

### 3.1 Agent 预设系统

预设系统自动扫描 `apps/cli/config/agent-presets/` 目录，发现并加载预设配置：

```
apps/cli/config/agent-presets/
└── crawl/
    ├── preset.yml           # 预设元数据
    └── agent.cordis.yml     # Agent 插件配置
```

预设加载流程：
1. 扫描目录结构
2. 读取 `preset.yml` 获取预设信息
3. 解析 `agent.cordis.yml` 获取插件配置
4. 注册到 dsh 预设系统

### 3.2 Persona 提示词设计

Persona 插件 (`@deepseek-ai/dsh-persona`) 提供采集专用提示词，定义 Agent 的行为规则：

**核心行为规则**：
1. **自动检测 URL**：识别 http:// 或 https:// 开头的链接
2. **自动采集**：检测到 URL 后自动调用 `crawl_fetch` 工具
3. **多 URL 处理**：支持一次输入多个 URL 的场景
4. **结果汇报**：统一汇报格式（保存路径、HTTP 状态码、内容摘要）

**引擎选择逻辑**：
- 默认使用 camoufox 引擎（抗检测浏览器）
- 支持用户指定其他引擎（scrapling、crawl4ai）

### 3.3 采集工具插件 (`tool-acquisition`)

**文件**：`BoBo/dsh/packages/acquisition/tool-acquisition/src/index.ts`

#### 3.3.1 工具注册

```typescript
export function apply(ctx: Context, config: Config): void {
  ctx.tools.register(defineTool({
    name: 'crawl_fetch',
    description: 'Fetch a webpage with the local Python engine...',
    parameters: { /* URL、引擎、选择器、输出文件 */ },
    output: { /* 保存路径、HTTP状态、内容预览 */ },
    async execute(args, _exec) { /* 工具执行逻辑 */ },
    presentCall: (args) => ({ /* 调用展示 */ }),
    presentResult: (_args, _result) => ({ /* 结果展示 */ }),
  }))
}
```

#### 3.3.2 配置接口

```typescript
export interface Config {
  pythonBin?: string      // Python 解释器路径
  scriptsDir?: string     // 采集脚本目录
  dataDir?: string        // 采集结果保存目录
  timeoutMs?: number      // 执行超时时间
}
```

#### 3.3.3 工具参数

```typescript
parameters: {
  url: { type: 'string', required: true, description: '目标网页 URL' },
  engine: { type: 'string', description: '引擎选择：camoufox/scrapling/crawl4ai' },
  selector: { type: 'string', description: 'CSS 选择器（Scrapling 专用）' },
  outFile: { type: 'string', description: '自定义输出文件名' },
}
```

#### 3.3.4 执行流程

```typescript
async execute(args, _exec) {
  const engine = args.engine ?? 'camoufox'
  const scriptArgs = [
    join(scriptsDir, `run_${engine}.py`),
    '--url', args.url,
    '--out', join(dataDir, outBase),
  ]
  
  // 调用 Python 脚本
  const res = await execFileAsync(pythonBin, scriptArgs, {
    timeout: config.timeoutMs,
    encoding: 'utf-8',
    windowsHide: true
  })
  
  // 解析结果
  const result = JSON.parse(res.stdout)
  return {
    savedTo: result.savedTo,
    status: result.status,
    contentPreview: result.preview
  }
}
```

### 3.4 Python 采集脚本

#### 3.4.1 Camoufox 引擎 (`run_camoufox.py`)

**文件**：`BoBo/scripts/run_camoufox.py`

**功能**：使用 Camoufox 抗检测浏览器抓取网页，支持 JavaScript 渲染。

**核心流程**：
1. 启动 Camoufox 浏览器（headless 模式）
2. 导航到目标 URL
3. 处理 Cookie 弹窗
4. 等待 JS 渲染和懒加载
5. 提取渲染后的 HTML
6. 保存到本地文件
7. 返回结果 JSON

**关键代码**：
```python
async def run(url: str, out: str, selector: str | None, auto_name: bool) -> dict:
    async with AsyncCamoufox(headless=True, exclude_addons=[DefaultAddons.UBO]) as browser:
        page = await browser.new_page()
        await page.goto(url, wait_until='domcontentloaded', timeout=120_000)
        
        # 处理 Cookie 弹窗
        await dismiss_cookie_overlays(page)
        
        # 等待 JS 渲染
        await page.wait_for_timeout(6000)
        for _ in range(4):
            await page.mouse.wheel(0, 1800)
            await page.wait_for_timeout(1200)
        
        # 提取 HTML
        html = await page.content()
        title = await page.title()
        
        # 保存文件
        Path(out).parent.mkdir(parents=True, exist_ok=True)
        with open(out, 'w', encoding='utf-8') as f:
            f.write(html)
        
        # 返回结果
        return {'savedTo': out, 'status': 1, 'preview': text[:2000], 'title': title}
```

## 5. 文件命名规则

### 5.1 自动生成命名

默认使用 `站点_标题_时间戳.html` 格式：

```python
def build_filename(url: str, title: str) -> str:
    host = urlsplit(url).netloc.replace('www.', '')
    host_s = safe_name(host, 40)
    title_s = safe_name(title, 60)
    ts = time.strftime('%Y%m%d-%H%M%S')
    return f"{host_s}_{title_s}_{ts}.html"
```

**示例**：
- URL: `https://news.qq.com/rain/a/20210912A0A92C00`
- 标题: `腾讯新闻`
- 文件名: `news.qq.com_腾讯新闻_20240101-120000.html`

### 5.2 自定义命名

## 6. 错误处理机制

### 6.1 网络错误

- **超时处理**：默认超时 120 秒
- **连接失败**：捕获网络异常，返回错误信息
- **DNS 解析失败**：捕获 DNS 错误，提示检查 URL

### 6.2 浏览器错误

- **启动失败**：Camoufox 启动异常处理
- **页面加载失败**：DOMContentLoaded 超时兜底
- **JS 执行错误**：捕获页面脚本错误

### 6.3 文件系统错误

- **目录创建失败**：自动创建父目录
- **文件写入失败**：权限错误处理
- **磁盘空间不足**：空间检查提示

### 6.4 错误返回格式

```typescript
// 工具层错误
throw new Error(`crawl_fetch 后台脚本执行失败: ${msg}`)

// Python 脚本错误
result = {'status': 0, 'savedTo': '', 'preview': f'ERROR: {e}', 'title': ''}
```

## 7. 性能优化

### 7.1 浏览器优化

- **Headless 模式**：无头运行，减少资源消耗
- **排除扩展**：排除 UBO 等扩展，加快启动速度
- **超时控制**：设置合理的超时时间

### 7.2 渲染优化

- **等待策略**：domcontentloaded 优先，超时兜底
- **懒加载触发**：滚动页面触发懒加载内容
- **Cookie 处理**：自动点击同意按钮，避免弹窗阻塞

### 7.3 文件优化

- **流式写入**：直接写入 HTML，不生成中间 JSON
- **编码统一**：UTF-8 编码，避免乱码问题
- **路径优化**：绝对路径，避免相对路径解析问题

## 8. 安全考虑

### 8.1 路径安全

- **绝对路径**：所有路径使用绝对路径
- **目录验证**：确保写入目标在允许范围内
- **文件名安全**：过滤特殊字符，防止路径注入

### 8.2 执行安全

- **超时限制**：防止无限期执行
- **资源限制**：浏览器内存和 CPU 使用限制
- **错误隔离**：捕获所有异常，避免进程崩溃

### 8.3 数据安全

- **本地存储**：所有数据保存在本地
- **无敏感信息**：不存储用户凭证或敏感数据
- **清理机制**：支持清理旧的采集数据

## 11. 扩展性设计

### 11.1 引擎扩展

支持添加新的采集引擎：

1. 创建新的 Python 脚本 `run_<engine>.py`

3. 更新 Persona 提示词中的引擎说明

### 11.2 功能扩展

支持添加新的采集功能：

1. **批量采集**：支持 URL 列表文件输入
2. **定时采集**：支持 cron 定时任务
3. **采集监控**：添加实时进度显示
4. **结果过滤**：支持按条件过滤采集结果

### 11.3 输出扩展

支持多种输出格式：

1. **HTML**：当前默认格式
2. **Markdown**：支持 Crawl4ai 的 Markdown 输出
3. **JSON**：支持结构化数据输出
4. **PDF**：支持页面转 PDF 功能
