# 23-技能库与品牌话术优化操作指南

> 本指南记录本次「技能库可见性修复 + 品牌话术收紧」的改动流程、根因分析与复现方法，方便以后维护与排查。

---

## 1. 本次优化背景（三个问题）

1. **AI 装上的技能，前端「技能库」看不到**：在对话里让模型安装 `hello_js_reverse_skill`，模型执行了安装，但「设置 → 技能库」不显示该技能。
2. **普通提问也回自我介绍**：没有发送"你好 / hello / 你叫什么"等关键词时，回复里仍带"你好！我是 BoBo…"这段自我介绍。
3. **前端「技能库」添加本地目录报错**：用「技能库 → 安装」选择 `E:\SmartBoBo\github project\hello_js_reverse_skill` 目录作为新技能，报错无法添加。

本次一并做了三处修复，并把技能名由 `hello_js_reverse_skill` 规范化为 `hello-js-reverse-skill`。

---

## 2. 根因分析

### 2.1 为什么 AI 装的技能不出现在前端「技能库」

- 前端「技能库」**只读** `C:/Users/Albet/.dsh/settings.yaml` 里的 `skill-library` 命名空间（`ui-settings-skills/src/client/store.ts` 的 `load()` 只取该命名空间的 `skills`/`groups`），**不会扫描磁盘上 `~/.dsh/skills/` 目录**。
- 模型当初按 `.agents/skills/install-mcp-and-skills/SKILL.md`（安装 SOP）把技能仓库 clone/复制进了 `~/.dsh/skills/hello_js_reverse_skill/`，但**没有登记**进 `skill-library` 命名空间 → 磁盘上有文件，UI 却读不到 → 技能库不显示。
- 该 SOP 第 3 步原本写着"把目录复制过去就会在技能库立即出现"，这句话**与实现不符**，是根因所在。
- 二次问题：该技能名含下划线，不满足 kebab-case 命名 `^[a-z0-9]+(?:-[a-z0-9]+)*$`，`skill-filesystem` 会**直接忽略**这个名字（`packages/skill/skill-filesystem/src/index.ts`），所以即便登记了也"能用但不加载"。

### 2.2 为什么前端「技能库」添加本地目录会报错

- `installLocal`（`packages/host/apiproxy/src/api-proxy.ts`）会读取所选目录下的 `SKILL.md` frontmatter 的 `name`（没有则取目录名），再用 `isSkillName` 校验。
- `hello_js_reverse_skill` 里的**下划线不是合法 kebab-case**，校验失败 → 返回 `skill name "hello_js_reverse_skill" is not a valid kebab-case name`。
- 报错与路径中 `github project` 的空格无关，**纯粹是技能名不合法**。

### 2.3 为什么普通提问也回自我介绍

- 自我介绍只存在于各预设 `persona` 的 `text` 里（没有硬编码字符串），原提示词只写了"命中问好关键词时必须回"，但缺少"不命中就不许主动自我介绍"的反向约束，模型（mimo-v2.5）于是在会话开头或普通回答里也自报家门。

## 5. 验证方法

1. **技能改名生效**：`~/.dsh/skills/hello-js-reverse-skill/SKILL.md` 的 `name` 为新名，目录名一致；`settings.yaml` 的 `skill-library.skills` 已含该条目。
2. **技能库可见**：重启后进「设置 → 技能库」，应看到 `hello-js-reverse-skill`（归入「逆向网页」分组，开关可用）。
3. **自动列出未登记技能**：临时把任意一个含 `SKILL.md` 且名字合法的目录放进 `~/.dsh/skills/`，但**不**登记 `skill-library`；刷新技能库，应自动出现该技能；打开其开关后，会被真正登记进 `skill-library.skills`。
4. **品牌话术**：发普通问题（如"采集 xxx 网页"）不再自带"你好！我是 BoBo…"；发"你好"/"你是谁？"才回固定开场句。
5. **前端安装本地技能**：用「技能库 → 安装」选择 `E:\SmartBoBo\github project\hello_js_reverse_skill`，现可通过（名已合法）；其他含下划线技能需先把 `SKILL.md` 的 `name` 改成 kebab-case。

## 6. 以后自己改要点

- **改技能名**：`SKILL.md` frontmatter 的 `name` 必须 kebab-case（小写字母/数字/连字符，禁下划线），且与 `~/.dsh/skills/<名>/` 目录名一致；改名后同步 `settings.yaml` 的 `skill-library.skills`。
- **改品牌话术**：7 个预设的 `persona → config → text` 里搜"你的正式身份是 BoBo"即可定位，改一处但 7 处同步；改完重启。
- **技能库数据源**：一律以 `~/.dsh/settings.yaml` 的 `skill-library` 命名空间为准；前端「技能库」只读它，`~/.dsh/skills/` 只是发现目录（供模型加载）。`discover` 仅把"未登记但存在"的技能补进列表展示，真正登记靠 `toggle`（首次打开开关）。
