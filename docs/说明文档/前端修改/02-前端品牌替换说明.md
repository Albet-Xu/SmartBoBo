# BoBo 前端品牌替换说明文档

## 1. 修改背景

将 DeepSeek Harness 前端界面品牌从 "DeepSeek HARNESS" 替换为 "SmartBoBo AGENT"，并将小鲸鱼图标替换为小菠萝图标，以符合 BoBo 智能采集平台的品牌形象。

## 2. 修改目标

1. **图标替换**：将小鲸鱼图标替换为小菠萝图标（仅轮廓，不包含白色背景）
2. **文字替换**：
   - 将 "deepseek" 文字替换为 "SmartBoBo"
   - 将 "HARNESS" 文字替换为 "AGENT"
   - 将 "探索未至之境" 替换为 "万物皆可得"
   - 删除 "预览版" 文字及方框
3. **样式调整**：优化图标和文字大小，确保视觉协调

## 4. 样式调整说明

### 4.1 图标大小

- **FishLogo 组件**: 默认大小 24px，宽高比 30:34
- **BrandWordmark 中的菠萝图标**: 缩放比例 0.65，实际尺寸约 20×22px

### 4.2 文字样式

- **"SmartBoBo" 文字**: 
  - 字体大小: 14px
  - 字重: 600 (半粗体)
  - 字间距: -0.01
  - 与 AGENT 徽章间距: 最小化（紧密排列）

- **"AGENT" 徽章**:
  - 字体大小: 14px（与 SmartBoBo 相同）
  - 字重: 700 (粗体)
  - 字间距: 0.8
  - 背景色: 使用当前颜色
  - 文字颜色: 使用反转标签颜色

### 4.3 颜色方案

所有图标和文字使用 `currentColor`，支持主题切换：
- 浅色模式: 黑色轮廓
- 深色模式: 白色轮廓（通过 CSS 媒体查询实现）
