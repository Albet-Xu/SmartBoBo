# BoBo 项目 UV 环境重构说明文档

## 1. 重构背景

BoBo 智能采集平台原先使用手动创建的 `venv/` 目录管理 Python 虚拟环境，这种方式存在以下问题：
- 环境文件存放不符合常规项目文件管理规范
- 依赖管理不够标准化
- 版本控制不够完善

## 2. 重构目标

将 BoBo 项目的 Python 环境从手动 `venv/` 迁移到 UV 标准管理，实现：
- 使用 `uv` 工具统一管理 Python 虚拟环境
- 采用标准的 `pyproject.toml` 配置文件
- 使用 `uv.lock` 锁定依赖版本
- 虚拟环境统一放在项目根目录的 `.venv/` 文件夹（UV 标准位置）

## 3. 重构内容

### 3.1 创建 `pyproject.toml` 文件

在 `BoBo/` 目录下创建 `pyproject.toml` 文件，内容如下：

```toml
# BoBo 智能采集平台 · Python 环境（由 uv 管理）
#
# - 虚拟环境统一放在项目根的 `.venv/`（uv 标准位置），用下面的命令创建/同步：
#     uv sync
# - Python 版本与依赖版本全部锁定在 `uv.lock`（应提交到版本库）。
# - 采集引擎以"本地路径依赖"引入（改源码即生效，等同 editable 安装）。

[project]
name = "bobo"
version = "0.1.0"
description = "BoBo 智能采集平台：本地 Python 采集引擎环境（camoufox / scrapling / crawl4ai）"
# 「环境容器」项目的 requires-python 选宽松值；实际解释器由 uv 与环境内依赖约束决定
requires-python = ">=3.10"
dependencies = [
    # 采集引擎 —— 见 [tool.uv.sources] 映射到本地 engines/ 路径
    # scrapling 的 StealthyFetcher 需要 fetchers 额外依赖（curl_cffi/playwright/patchright 等）
    "scrapling[fetchers]",
    "crawl4ai",
    # 默认抗检测浏览器引擎（从 PyPI 安装）
    "camoufox>=0.5.5",
]

[tool.uv.sources]
# 本地源码路径依赖（editable），映射到 engines/ 下的引擎源码
scrapling = { path = "engines/scrapling" }
crawl4ai  = { path = "engines/crawl4ai" }

[dependency-groups]
dev = [
    "pytest",
]

[tool.uv]
# 本项目只是"Python 环境容器"，本身不构建/分发任何 Python 包，
# 标记为非 package（virtual project），只安装其依赖、不安装本包自身。
package = false
# 版本覆盖：camoufox 要求 playwright<1.61，而 scrapling[fetchers] 声明 >=1.61，
# 二者在严格解析下冲突。实测 playwright 1.60 可同时满足两者（旧环境即如此），
# 故以 override 统一到 <1.61，复现已验证可用的组合。
override-dependencies = [
    "playwright<1.61",
]
# 虚拟环境目录（uv 默认即 .venv，此处仅作说明）
# venv = ".venv"
# 固定解释器版本：见项目根的 `.python-version` 文件（`uv python pin 3.13` 生成）。
# 也可用 `[tool.uv] python-preference` 控制解释器来源偏好。
```

## 4. 环境创建和同步命令

### 4.1 首次创建环境

```bash
cd E:/SmartBoBo/BoBo
uv sync
```

### 4.2 安装依赖

```bash
# 安装所有依赖
uv sync

# 仅安装生产依赖
uv sync --no-dev

# 安装特定依赖
uv pip install scrapling[fetchers]
```

### 4.3 激活虚拟环境

```bash
# Windows
.venv\Scripts\activate

# Linux/Mac
source .venv/bin/activate
```

### 4.4 运行 Python 脚本

```bash
# 使用 uv 运行
uv run python script.py

# 或激活环境后运行
.venv\Scripts\python.exe script.py
```


## 7. 注意事项

1. **版本锁定**: `uv.lock` 文件应提交到版本库，确保团队成员使用相同的依赖版本
2. **路径配置**: Windows 路径使用正斜杠 `/` 或转义反斜杠 `\\`
3. **依赖冲突**: playwright 版本冲突已通过 `override-dependencies` 解决
4. **虚拟环境**: 不要手动删除 `.venv/` 目录，使用 `uv sync` 管理环境
