# SmartBoBo · BoBo 智能采集平台

一款 **全自动化的 AI 数据采集智能体**（桌面版）。你只要用自然语言告诉它要采集什么，它就会用真实浏览器访问网页、抓取内容，并按需把数据写入数据库。内置 DBX 数据库面板与逆向/工作流能力，开箱即用、可跨机离线运行。

当前版本：**v1.4.0**

---

## 一、项目简介

BoBo 是基于 **DeepSeek Harness（dsh）** 构建的本地智能采集平台，采用 Electron 原生窗口打包。接收者**无需预装 Node / Python / 浏览器，也无需联网**即可安装使用。

它对网页做采集的方式是「真实浏览器渲染」：内置 **Camoufox**（抗检测浏览器，单一采集引擎），能处理 JS 渲染、弹窗、动态内容，并把整页内容保存下来。

### 内置能力一览（v1.4.0）

| 能力 | 说明 |
| --- | --- |
| 🕷️ 网页采集 | 自然语言下达任务，采集引擎把页面 HTML/正文存到本地 `data/` |
| 🔄 三种模式 | **采集模式 / 逆向模式 / 工作流模式**（Agent 预设，设置里切换） |
| 🗄️ 内置 DBX 数据库面板 | 支持 90+ 种数据库的连接、查询、管理（Kafka 等内置驱动**离线可用**） |
| 📥 采集入库工作流 | 复用内置 DBX 已存连接，采集 → 逐字段确认 → 写入数据库（UPSERT 去重/更新） |
| 🧠 逆向经验沉淀（RAG） | 逆向成功/失败经验自动沉淀为本地 MD + 向量化入 Qdrant，新站点前检索历史案例避免踩坑 |
| 🛡️ 反爬逆向调试 | 内置 camoufox-debug 工具（主世界执行 / 网络捕获 / cookie / websocket） |
| 🌐 代理池 | 内置代理池管理与代理命令 |
| 🛠️ 技能库 / MCP 工具 | 按需加载技能（如 db-提取入库、逆向-爬虫模板）、MCP 工具集 |

### 技术栈

- **桌面壳**：Electron 31（原生窗口）
- **后端**：DeepSeek Harness（dsh，pnpm monorepo，Cordis 插件体系）
- **采集引擎**：Camoufox（Python，单一引擎）
- **数据库面板**：DBX Web（Rust + Vue，内置）
- **Python 环境**：Python 3.13 + uv
- **向量库**：Qdrant（可选，用于逆向经验 RAG）

## 四、安装步骤

1. 双击 `BoBo-Setup-1.4.0.exe`；
2. 选择安装目录（默认即可），点击「安装」；
3. 安装完成后桌面上会出现 **BoBo** 图标；
4. 双击 **BoBo** 启动：
   - 先弹「启动进度」小窗，首次会**从内置离线依赖重建环境**（无需联网，约 20–60 秒），请耐心等待；
   - 自动进入主界面（内嵌浏览器窗口，地址 `http://127.0.0.1:7070`）；
   - 关闭窗口即退出，并自动停掉后台服务。

**卸载**：控制面板 → 卸载程序 → BoBo（安装包自带卸载项，卸载不影响你的 `BoBoData` 用户数据）。

## 五、安装后的配置（★★ 必读）

装好后只需填一个 **DeepSeek API Key** 即可正常采集；数据库能力按需配置。

### 5.1 必配：DeepSeek API Key

1. 打开 BoBo → 左下角/设置（齿轮）；
2. 找到 **API Key 配置**（对应 DeepSeek），填入你自己的 `sk-xxxx`；
3. 保存。此后对话/采集即可使用。

> Key 不随安装包分发、不进源码，属个人配置。Key 失效或更换时到该设置里修改即可。

### 5.2 数据库面板（DBX）—— 内置驱动离线可用

左侧导航栏「数据库」图标 → 打开内嵌 DBX 面板（`http://127.0.0.1:4224`）。

- **Kafka 等内置 Agent 驱动**：v1.4.0 起安装包已内置驱动运行时（托管 JRE + Kafka 驱动），首次启动自动装载，**离线即可连接**，不再提示缺少驱动。
- **新建连接**：在 DBX 面板选数据库类型 → 填主机/端口/账号等 → 保存并测试连接。

### 5.3 Qdrant 连接（用于「逆向经验」向量库，可选）

Qdrant 不是内置 Agent 驱动，走 **JDBC 插件**。两种配法任选其一：

- **方式 A（通过 DBX，推荐）**：在 DBX 面板新建连接选 **Qdrant**，填公司服务器地址（如 `192.168.x.x`）、端口 `6333`、API Key（如要求），保存并测试成功；RAG 记忆库会自动找到 `db_type == qdrant` 的连接作为向量库。
  - > 若提示缺少 JDBC 驱动：在 DBX「驱动管理」里导入安装包自带的 `resources\runtime\dbx-offline\dbx-jdbc-plugin-*.zip`（或在下载镜像里选阿里云/华为云/腾讯云）。
- **方式 B（环境变量直连，不经 DBX）**：设置环境变量
  - `REVERSE_MEMORY_QDRANT_URL=http://<公司服务器>:6333`
  - `REVERSE_MEMORY_QDRANT_API_KEY=xxx`
  - 集合名固定 `reverse_experience`，首次写入自动建集合。

### 5.4 （可选）代理池

若需通过代理采集/逆向，按应用内「代理」指引填入代理配置即可。

### 5.5 用户数据目录

- 用户数据（会话、设置、API Key、日志、DBX 连接等）存放在安装目录同级 **`BoBoData/`**（随安装盘走，升级/卸载不影响）。
- 采集产物默认落在**当前会话工作区**的 `data/` 下。

## 六、使用方式

启动后直接在对话框用自然语言下达任务：

- **采集**：「请采集 https://example.com 这个网页」
- **采集入库（工作流）**：「把 https://… 采集后写入数据库表…」（会复用 DBX 已存连接，逐字段向你确认后 UPSERT 写入）
- **逆向**：遇到反爬/登录/签名混淆的站点时可用逆向模式就地破解并沉淀经验

详细操作指引见仓库 `docs/说明文档/`（功能实现 03–32、操作指南等）。

## 七、常见问题（FAQ）

| 现象 | 处理 |
| --- | --- |
| 启动进度窗卡在「依赖就绪失败」 | 极少见；看日志 `<BoBoData>/electron/bobo-pnpm.log`，多为磁盘/杀软拦截，重试启动 |
| 智能体不回复 | 检查设置里的 DeepSeek API Key 是否有效 |
| Kafka 连不上 | 确认已更新到 v1.4.0（旧版安装包未内置驱动）；新建连接时类型选 Kafka，检查主机/端口/鉴权 |
| 某些网站采集不到 | 多为强反爬/需登录；用逆向模式就地处理，或为该站点配置登录态/代理 |
| 端口被占用 | 7070 或 4224 被占用时关闭占用进程后重启 BoBo |

## 八、面向开发者

仓库为源码工程（`bobo-application-02` 分支）。

```bash
# Python 环境（单引擎 camoufox）
uv sync
uv run camoufox fetch

# dsh 后端
cd dsh
pnpm install
pnpm run build

# 启动（源码模式）
pnpm bobo            # → http://127.0.0.1:7070
```

- 打包：`cd desktop && npm run dist`（产物在 `desktop/release-<版本>/`，安装包命名 `BoBo-Setup-<版本>.exe`）。
- 详细架构与二次开发见 `docs/说明文档/00-BoBo项目修改总览.md`、`32-采集引擎单一化与跨机交付操作指南.md`。
