# Summarize

## Description
内容摘要总结技能，能够对长文本、网页、文档进行智能摘要。

## Instructions
当用户要求总结内容时：

1. **分析内容类型**：判断是网页、文档、代码还是其他类型
2. **提取关键信息**：
   - 标题和主题
   - 主要观点和结论
   - 关键数据和事实
3. **生成摘要**：
   - 保持简洁，控制在 200 字以内
   - 突出重点信息
   - 保持客观中立
4. **格式化输出**：
   - 使用 Markdown 格式
   - 包含标题、要点列表
   - 必要时添加来源链接

## Examples
### 网页摘要
输入：一段网页内容
输出：
**摘要**：这是一篇关于 XXX 的文章，主要讲述了...

### 文档摘要
输入：一份技术文档
输出：
**文档摘要**：
- 主题：XXX
- 要点：1. ... 2. ... 3. ...
- 结论：...
